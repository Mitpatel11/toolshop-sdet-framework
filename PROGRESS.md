# Daily Progress Log

One entry per session, appended in order. This is the honest record — planned
vs actual, what was learned, what got deferred. It's also what makes the
commit history explainable later: every commit should map to an entry here.

## Template
Every day opens with the brief (this is also the video's cold open) before any
code or explanation:
```
## Day <N> — <date>

### Goal
<one sentence — why today's topic exists in the framework>

### Objectives
- <objective 1>
- <objective 2>

### Definition of Done
- [ ] <concrete, checkable outcome>
- [ ] <concrete, checkable outcome>

---
- Sprint: <sprint #>
- Actual: <what really got done — note if it ran long/short and why>
- Time spent: <Xh Ym> (target 1-2h)
- What I learned:
- What I struggled with / took longer than expected:
- Deferred to BACKLOG.md: <link or "none">
- Bugs logged to ISSUES.md: <link or "none">
- Commit(s): <hash — message>
```
