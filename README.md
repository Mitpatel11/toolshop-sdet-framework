# Toolshop SDET Automation Framework

A Playwright + TypeScript test automation framework built against
[Practice Software Testing (Toolshop)](https://github.com/testsmith-io/practice-software-testing),
covering UI, API, database, and performance testing layers.

Work in progress — built incrementally, one layer at a time.

## Stack
- Playwright + TypeScript
- API testing with Zod schema validation
- MySQL validation layer
- Data-driven testing (JSON/Excel/Faker)
- BDD with `playwright-bdd`
- CI/CD via GitHub Actions + Docker Compose
- Allure reporting
- k6 performance testing
